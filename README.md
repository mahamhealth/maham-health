# Maham Health

Next.js medical travel landing-page MVP. Features multilingual RTL/LTR content, treatment price comparisons, concierge packages, a consultation wizard, and a demo travel-advisor widget.

## Run locally

```bash
npm install
npm run dev
```

Prices and medical service claims are demonstration content and should be independently verified before publication. The consultation form is a frontend demo and does not transmit or securely store patient data.
